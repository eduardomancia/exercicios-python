## Sobre esse projeto
Neste repositorio estao reunidos os 25 exercicios de Python propostos nas aulas. Cada exercicio foi desenvolvido em seu proprio arquivo separado (do ex-01.py ao ex-25.py), facilitando a consulta do codigo e o teste individual de cada um pelo terminal.

---

## O que usei
* **Linguagem:** Python
* **Versao:** Python 3.12.10

---

## Como baixar e rodar no seu computador

Para testar os exercicios na sua maquina, basta seguir estes passos:

1. Clone o repositorio (ou baixe os arquivos):
```bash
git clone https://github.com/eduardomancia/exercicios-python.git
```

2. Acesse a pasta do projeto:
```bash
cd exercicios-python
```

3. Execute o exercicio que deseja testar digitando python e o nome do arquivo. Exemplos:
```bash
# Para testar o exercicio da senha:
python ex-13.py

# Para testar a tabuada:
python ex-14.py

# Para testar a lista invertida:
python ex-25.py
```
